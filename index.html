Backend API & Sistem Informasi Donor Darah Lamongan

Aplikasi berbasis website dan mobile terintegrasi untuk mengelola siklus donor darah, verifikasi pemohon oleh admin, serta notifikasi darurat cepat ke para pendonor.

Peran Saya Backend & Database Developer

Masalah yang Dihadapi (Problem)

Kebutuhan darah darurat membutuhkan penanganan cepat dan terkoordinasi. Pengajuan darah harus divalidasi keabsahannya oleh admin sebelum disiarkan ke pendonor, sekaligus memerlukan penentuan lokasi yang presisi agar bantuan segera tersalurkan.

Solusi Backend (Solution)

Membangun arsitektur backend dengan Python dan database MySQL yang menyediakan endpoint REST API untuk melayani antarmuka client (Flutter). Mengimplementasikan logika otorisasi multi-peran (RBAC), alur persetujuan admin bertingkat, dan pengiriman notifikasi darurat otomatis saat kondisi darah kritis.

Fitur Backend yang Saya Kembangkan:

  • Autentikasi & RBAC: Pembagian hak akses terpisah untuk Pemohon Darah, Pendonor, dan Administrator.
  • Alur Validasi & Approval Admin: Endpoint khusus untuk memvalidasi formulir permohonan darah sebelum diteruskan ke pendonor.
  • Notifikasi Darurat Kritis: Mekanisme broadcast notifikasi segera ke pendonor yang sesuai saat stok darurat dibutuhkan.
  • Tracking Map Data Endpoint: Penyediaan data koordinat lokasi untuk pemetaan jarak fasilitas dan kebutuhan darah.
